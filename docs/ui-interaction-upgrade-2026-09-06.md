# UI 与交互优化 · 2026-09-06

构建标识：`creative-upgrade-2026.09.06-ui.1`。沿用浅蓝灰、白色稿纸和低饱和绿色；不调整模型调用、候选确认和正式内容写入的业务规则。

## 本轮交付

- 章节标题、布局控制、版本操作和正文生成分层排列；增加专注写作及写作镜头开关。专注模式退出后恢复原布局，不修改侧栏偏好。
- 字段 AI 辅助按钮降为浅色次要操作，整卡生成保留主操作层级；主要确认按钮加强文字对比度，禁用状态仍可读。
- 分裂按钮菜单脱离滚动容器，自动避让屏幕边缘。支持点击外部关闭、方向键、Home/End 和 Esc，关闭后返回触发按钮。
- 章节标签页支持左右方向键和 Home/End；章节定稿弹层支持焦点约束、Esc 关闭及焦点返回，增加三步进度提示。
- 就地候选：默认正文阅读视图，可切换差异；预览独立滚动，确认操作固定在底部。宽工作区中对话与候选并排；工作区宽度不超过 950px 时切换“候选内容 / 创作对话”。
- 讨论记录及选区保护放入可滚动历史区域，输入框不再随历史无限长高；重新开始收进对话选项。
- 故事基础、人物、世界观与结构规划统一响应式容器；窄桌面下候选区移至表单后，页头“查看候选”可直接定位。知识和文风页对应侧栏也按窄屏顺序排列。
- 规划标题区按项目默认执行方式显示 Codex，保留应用模型配置入口。主编辑稿字号调整为 16px，不改动正文或其段落。

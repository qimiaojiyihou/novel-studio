# 创作体验升级 · 工程交付记录

构建标识：`creative-upgrade-2026.09.06`。数据库版本：24。项目备份格式：8。

## 已接入的创作入口

### 阶段一：模型、规则与定稿

- 模型设置提供可搜索的 Codex 模型列表、高级 ID 和刷新目录；`gpt-6-astra` 显示为 GPT-6 Astra，不改变已有默认值。内置名称不代表运行时已经支持。目录刷新创建无项目内容的诊断会话，不发送创作 prompt；显式模型及参数设置后回读，不符则停止。
- 新运行冻结模型配置与提示词上下文，继续旧对话保持锁定模型；换模型用“使用新模型完全重新开始”。ACP 首个输出后的故障不会偷偷重跑 exec 或应用模型。
- 官方能力包 1.3.0 增加精简章节流程；完整流程保留。旧项目在创作助手预览并确认升级，历史包读取固定构建产物。既有正文与长章节卡保留。
- 章尾支持语义边界和原句边界。通用新版提示词不携带悬疑案例的特殊钥匙、门后声音等情节要求。自然度依靠视角、对白目的、细节取舍，不用短句比例约束。
- 正文编辑及候选自动本地检查。字数偏差属于编辑提示，不触发结构重试。JSON/必需字段的结构重试仍最多三次。
- “完成本章”锁定正文版本，经独立审稿、作者判断、带原文证据的章后状态提取及集中确认，写入单一章节记忆。重复启动聚焦已有任务；修改正文或依赖使旧产物过期。确认交接与候选状态更新在同一事务中。
- 完整工作流中的质量评审也分配独立子运行；主笔后端与评审后端分别记录。精简流程的正式定稿入口使用现有质量评审路由，或作者选择的 Codex 新会话。

### 阶段二：作者修改与表达

- 就地对话区区分讨论与修改。讨论保存答复而不创建替换候选；修改支持相关句段、选区、圈选场景及明确的整章重构。
- 局部修改返回来源摘要、原文与 UTF-16 位置补丁，应用校验后组装完整稿；位置、重叠、来源和保护文本错误均停止应用，不扩大修改范围。
- “保留这段”保存来源绑定的保护范围。手动编辑候选再确认；编辑已接受版本产生作者修订候选，保留原版历史。
- 正式章节卡可展开表单手动编辑和保存，无须编写 JSON。候选编辑器保留高级数据视图。
- “提示词与文风 → 认可片段”保存来源版本、片段和认可原因，可修改、停用或删除。最多召回三段风格样本，并与正式事实区分。
- 人物详细字段增加说话目的、社交面具、语言习惯和禁区。人物整卡与字段协作共用创作会话。
- “结束本次连接”释放连接并保留历史；关闭面板仅隐藏。缺少完整冻结信息的旧运行在继续前要求明确选择旧规则或新建升级运行。

### 阶段三：来源与长期记忆

- 在既有章节记忆与知识表增加来源、证据、生效章节和知情范围；普通保存只使已确认交接待检查，不覆盖已确认摘要。
- 上下文优先任务、硬事实与已确认交接，再按本地实体和段落检索引入人物、伏笔和风格。必需事实超过字符预算会提示缩小范围，省略的可选资料列入诊断。
- 候选、审稿及定稿记录实际依赖摘要。相关内容变化才使产物过期；故事基础等全局依赖明确列出。人工评分不会恢复已过期报告的通过标志。
- v22/v23/v24 顺序迁移；备份升级到 v8，兼容旧格式，恢复未完结定稿为待恢复状态。备份继续排除凭据、原始 ACP 会话 ID 与完整工具日志。

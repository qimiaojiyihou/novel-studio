# 短故事创作

在左侧作品菜单选择「新建作品 · 小说 / 短故事」，再选择「短故事」。填写标题、题材、想法和文风即可开始，也可设置 800—12000 字的全文目标（默认 8000 字）。

短故事使用单篇正文。编辑器提供正文、故事卡、场景计划，保留自动保存、版本恢复、排版、模型续写与整篇重写、朱雀检测和定稿能力。全文目标可在「编辑故事信息」修改。创作助手沿用已有执行器与模型路由，按完整短篇的冲突、转折与结局组织创作和评审。

书库会标注小说或短故事。短故事导出 TXT、Markdown、Word 时只包含作品标题与正文，Word 延续正文无空段、首行缩进的排版。项目备份 v9 保存作品形式、全文目标和既有历史；旧版本备份仍按小说恢复。普通 TXT/Word 文稿没有作品形式元数据，导入行为仍沿用小说项目。

存储 schema v36：projects.work_format 使用 novel/short_story，缺省为 novel；project_type 继续专用于 user/benchmark。现有小说迁移后保留原内容、章节和工作流。短故事在存储层限制一篇正文，避免外部创作接口误增章节。

# 手机阅读站：1Panel / txt.zhijianku.com

## 边界

阅读站是独立部署的只读稿件发布服务，不是对本机书库开放公网访问。
本机 SQLite 仍是创作主库；云端 `reader.sqlite` 只包含明确发布的正文、书名、题材、公开简介、目录、阅读账号哈希与会话。
不上传设定、故事种子、候选、创作对话、检测结果、模型凭据、审批或原始书库。
部署新阅读站不代表同意上传任何真实稿件。首次上传必须在 Novel Studio 确认。

## 服务器部署

服务使用 Node.js 24 内置 SQLite，无 npm 依赖。建议用仓库的 `reader-service/` 单独部署 Docker。
以下是部署步骤，不会通过打开本地 Novel Studio 自动执行：

1. 将 `reader-service/` 目录复制到服务器独立目录，例如 `/opt/novel-reader`，不是整份书库。
2. 在此目录建立 `data/`，由容器内 node 用户（UID/GID 1000）写入。保存权限建议 0700。
3. 通过 `openssl rand -hex 32` 在服务器生成发布凭据，填入 1Panel 编排的 `READER_ADMIN_TOKEN` 环境变量（或本目录私有 `.env`，权限 0600）。不提交凭据、不在日志或对话里粘贴。
4. 在 1Panel 容器编排导入 `compose.yaml`，从当前目录构建，启动。核对端口仅绑定服务器 `127.0.0.1:3080`，不把 3080 暴露公网。
5. 将域名 `txt.zhijianku.com` 解析到服务器；在 1Panel 网站配置反向代理到 `http://127.0.0.1:3080`，配置有效 HTTPS 证书，HTTP 跳转 HTTPS。
6. 如果 1Panel 的 OpenResty 本身在容器中，容器内 127.0.0.1 不是宿主机：使用可访问的宿主机地址和受防火墙限制的端口，或将两个容器加入独立共用网络，反代 `http://novel-reader:3080`，并移除宿主机端口映射。按照实际网络模式选择，不盲目开放 3080。
7. 反代保留 `Host` 与 `Origin`；单次请求上限至少 2 MiB、超时至少 35 秒；关闭代理正文缓存，不开启公开目录或数据库静态文件访问。可另外配置登录路径请求限速。服务不信任 X-Forwarded-For 来判定用户身份。
8. 核对 `https://txt.zhijianku.com/api/session` 返回 JSON，初始 `requireLogin: true`。初始没有账号、没有书籍，匿名读者读不到正文。

若域名已有业务，先用独立路径以外的测试子域名并相应调整 `READER_ORIGIN`；此版本要求部署在域名根路径，不覆盖已有网站。
账号、网络与公网发布涉及的当地要求由站点负责人核对；本文件不代替这些准备。

## Novel Studio 设置

模型与项目设置 → 手机与云端阅读：

1. 填入 `https://txt.zhijianku.com` 与服务器发布凭据，保存连接、检查阅读站。凭据通过系统密钥加密保存；不回传界面。
2. 添加至少一个阅读账号（密码至少 10 位）。可修改密码、禁用、删除；登录模式至少保留一个可用账号。
3. 按需切换“需要登录后阅读”。关闭登录会出现公开确认，影响全站所有已发布书籍。
4. 选择具体书籍，填写公开简介（可留空，不以故事种子代填），选择范围：仅已定稿或全部非空已保存正文（含草稿）。保存设置，再点击发布并核对确认弹窗。
5. 首次发布成功后可以仅对此书开启“保存后自动同步”，保存设置。约每 30 秒比较章节元数据，变化时才读取正文并上传变化章节。前台切书不改变项目 ID 绑定。

“全部正文”适合作者手机看最新保存稿：人工改字保存后也会同步，未接受的 AI 候选不发布。
“仅定稿”自动同步时保留修订中或本地暂时删除章节的云端旧版；下一次定稿再更新。手动发布则严格以当前范围替换云端目录，确认中会提示排除的章节撤下。
如需立即撤回整本书使用“下架”，同时关闭该书自动同步。
修改连接域名会清除本机此阅读站的发布绑定与凭据，需要重新配置和首次确认，不会把稿件自动发往新站点。
切换另一台电脑后需重新输入发布凭据，系统加密凭据不会跨电脑直接解密。

## 同步与一致性

- 按固定项目 ID、章节 ID 发布。云端只接受管理凭据，不开放任何创作操作。
- 先上传目录清单，按 SHA256 找出变化正文，再逐章上传；校验全部章节后一个事务切换可读版本。
- 超时、断线、正文来源变化、并发版本变化时保留云端旧版；重复上传/提交幂等，不重复创建章节。
- 上传过程中本地来源变化时取消本次切换，重新同步。云端被另一作者端修改或下架时，自动同步暂停并显示原因，需人工核对。
- 临时发布与上传 24 小时过期，后续发布清理；最多 100 个未完成发布，不无限保留运行事件或正文历史。完成发布立即清除临时上传正文。
- 临时断网、限速和服务器故障按 30 秒至 5 分钟退避重试，界面显示下次重试时间；鉴权失败、正文冲突或云端被另一端修改则暂停该书，需人工核对后重新开启，不产生事件记录或重试风暴。
- 退出应用中止网络请求，下次启动恢复明确开启的同步设置。电脑关机时可读最后成功发布版本。
- 自动发布不是书库备份，不替代本地备份。下架或撤销访问也不会撤回读者已经复制的内容。

## 手机阅读

手机浏览器访问域名，公开模式直接进入书架，登录模式先输入阅读账号。
默认按实际可用视口与字体 CSS 多栏分页：点击右侧/左侧或滑动翻页，中央打开菜单；到章节末尾跨章。
支持宋体/黑体、字号、行距、浅色/护眼/夜间主题。书架使用紧凑横向书卡，显示题材、章节数、更新时间和本浏览器上次阅读章号；支持按书名/题材搜索、最近更新/书名排序。旧书签只有章节 ID 时显示“已保存上次阅读位置”，继续阅读后补存章号。
目录每页 25 章，列表在弹窗内独立滚动，顶部查找和底部分页固定可见。打开目录自动定位当前章所在页；支持按章节名称搜索、选择章节范围、输入实际已发布章号直达、正序/倒序排列和“当前章”定位。搜索无结果或输入未发布章号时有明确提示，不触发正文加载。
目录只有当前页的最多 25 个章节按钮，章节范围下拉只包含每页起止章号；5000 章产生 200 个范围选项，不生成 5000 个目录按钮。搜索和排序只处理已取得的目录元数据，不读取全书正文。书架只请求书籍元数据，不预加载各书正文。
默认平移翻页：横向拖动跟手，短距离慢滑回弹，超过阈值或快速轻扫切换一页；连续点击在过渡期间不跳页。纵向手势和文字选中不触发翻页。
中央菜单的“翻页效果”可切换“平移 / 无动画”，偏好保存在当前浏览器；系统设置减少动态效果时自动关闭动画。
仅在接近章节边界时预取相邻正文，内存最多缓存三章，不预加载整本书；跨章等待网络时保留当前页，失败后停留原章节并支持重试。离开书籍、版本更新或退出登录时清空缓存。
阅读位置保存“章节 ID、正文字符位置、局部锚点、内容摘要”，调整字号/旋转后尽量保留位置；文本更新时锚点失效会近似定位，不承诺任意大改均能精确恢复。
更新提示不替换正在阅读的正文，读者手动点击后加载新版。
支持 Web App manifest 和添加主屏幕；没有 service worker，不缓存离线稿件，不提供跨设备进度同步。
切换私有访问后服务器正文接口立即要求登录；已打开页面下一次状态检查或操作会退出并清除正文 DOM。已看见或已复制的内容不可能通过访问开关收回。
Safari/Chrome 真机仍需按具体设备验收浏览器地址栏、安全区、字体和手势；桌面模拟测试不等于真机验收。

## 运维

- 备份独立 `/app/data`。运行中不能只复制 `reader.sqlite` 而漏 WAL；使用 SQLite 在线备份，或先正常停止容器再备份完整目录。备份属于阅读副本，不是本机主书库。
- 更新服务先备份阅读数据库，再替换代码重新构建；不要删除数据卷。
- 管理凭据泄露时生成新凭据、重启容器、在 Novel Studio 更新连接。不要把管理凭据交给读者。
- 定期更新 Node 24 镜像并保持 HTTPS 证书有效。日志轮换已限制大小，不记录正文、密码、凭据与每次阅读事件。
- 静态文件仅白名单路由，正文动态接口强制鉴权、no-store。非同源浏览器请求拒绝；密码采用带随机盐的 scrypt，Cookie 为 HttpOnly/Secure/SameSite=Strict；修改账号撤销会话。
